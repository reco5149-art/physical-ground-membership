### 주요 구현 결정

1. **연락처 자동 정규화**: 입력값에서 숫자만 추출해 `010-1234-5678` 형태로 통일 저장한다. 검색 일관성을 위해서다. (서울 지역번호 `02`는 앞자리 2자리로 처리)
2. **연락처 중복 차단**: 출석 체크 시 연락처가 회원 식별의 핵심 키라, **활성 회원 간 연락처 중복을 막는다.** 중복 시 기존 회원 이름을 알려준다. 비활성 회원과의 중복은 허용(재등록 대비).
3. **삭제 = 비활성화**: PRD대로 하드 삭제 대신 `status='inactive'`로 처리해 출석 이력을 보존한다. 목록 기본값은 활성 회원만, "비활성 포함 전체" 토글 제공.
4. **검색어 살균**: PostgREST `or()` 필터 구문을 깨뜨릴 수 있는 문자(`, ( ) * \`)를 제거한 뒤 필터에 넣는다.
5. **검증은 순수 함수로 분리**: `validateMemberInput`을 UI/DB와 분리해 단위 테스트가 가능하게 했다.
6. **목록 100건 제한**: MVP 규모(수천 명)에서 페이지네이션 대신 상한 + 검색으로 대응. 100건 도달 시 화면에 안내 문구를 띄운다. 회원이 늘면 페이지네이션 필요.
